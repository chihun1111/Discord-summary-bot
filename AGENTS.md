# Repository working agreement

- Manage project changes with Git. The origin repository is `https://github.com/chihun1111/Discord-summary-bot.git`; the main branch is `main`.
- Inspect the working tree before editing and preserve unrelated changes.
- Validate each change with relevant checks, then create a descriptive commit for the completed work.
- Never commit credentials, `.env`, chat databases, deployment credentials, or local agent runtime state. Keep `.env.example` limited to placeholders.
- Do not force-push or rewrite shared history unless explicitly requested.
- For Hermes deployments, preserve the server's `.env` and `data/` and verify the running bot after deployment.
